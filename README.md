# Proyecto - Sprint 0

Estructura inicial de una aplicación web.

## Estructura

- `index.html`: presentación mínima del proyecto.
- `js/app.js`: datos de ejemplo y salida por consola.

## Ejecutar

Abre `index.html` en un navegador y consulta la consola de herramientas de desarrollo para ver el elemento de ejemplo.

El elemento contiene nombre, descripción, fecha de entrega y prioridad numérica.
